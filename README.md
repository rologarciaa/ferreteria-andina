# Ferretería Andina

Sistema web para la gestión de productos, inventario y ventas.

## Curso

Herramientas de Desarrollo

## Integrantes

- Integrante 1: Rolando


## Funcionalidades actuales

- Registro de productos.
- Listado de productos registrados.
- Visualización de código, nombre, categoría, precio y stock.

## Instrucciones de ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `frontend/index.html`.
4. Ejecutarlo en un navegador web o mediante Live Server.
5. Registrar un producto mediante el formulario.
